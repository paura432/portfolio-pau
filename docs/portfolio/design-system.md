# PAU / SYSTEMS — Design direction

## Idea

Un atlas interactivo de la evolución de Pau Ramos: systems engineering, infrastructure y AI product work.

## Sistema visual

- Base: warm white, graphite, gris técnico y cobalt restringido.
- Display: Geist Sans con escala extrema y tracking negativo.
- Metadata: Geist Mono.
- Grid: líneas, coordenadas, módulos y nodos; no cards apiladas.
- Motion: línea, foco y cambio de estado. Nunca decoración continua.

## Regímenes

| Capítulo | Lenguaje |
| --- | --- |
| Home | Atlas editorial y topology. |
| OVI | Claro, calmado, connected. |
| DUPLEX | Industrial, diagnóstico, safety orange. |
| TrustOS | Negro, credencial e infraestructura. |
| Foundations | Documento técnico y diagrama. |
| Design | Editorial, imagen y tipografía. |

## Responsive

- Móvil: nodos como secuencia legible; ninguna información depende del gráfico.
- Desktop: topology como canvas ancho; texto sigue columnas estrechas.
- Reduced motion: sin transición de nodos ni parallax.

## Accesibilidad

- Cada diagrama lleva equivalente textual.
- SVG decorativo no recibe foco.
- Interacciones de Foundations tienen botón o slider semántico.
